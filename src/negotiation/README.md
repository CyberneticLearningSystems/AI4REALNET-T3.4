# Negotiation Proxy
This folder contains all files pertaining to the automated negotiation between agents in the automated system. 

:construction: Work in Progress :construction:

The current outline for the negotiation proxy consists of a series of parameters which define the preferred weighting of objectives by the human operator. The negotiation is planned to be carried out using a bidding method, wherein agents put forward the expected reward of their local solution. In combination with the solution parameters set by the human, the solutions are compared, and the prevailing solution chosen.
